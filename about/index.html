About

Hi, I’m Ayoub El-Mahjouby, aka mahroot.

I’m a Moroccan software engineer, working on the backend and infrastructure side of things. I like to understand what’s under the hood, so I learn by building things from scratch: a storage engine (my engineering thesis), a mini Spring framework, my own Java collections.

Right now I’m going deep on Linux and Kubernetes, and back to the fundamentals: operating systems, networks, databases, distributed systems. I mostly write Go, and Java when it fits.
